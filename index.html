About the project

CK Fantasy Manager is an educational systems design and personal software development project. Its initial scope is one authorized fantasy football manager in one Yahoo Fantasy league, for private, noncommercial use.

The planned application is read-only and will not submit roster changes, trades or waiver claims. Live Yahoo Fantasy Sports API integration is pending approval. This public website is informational only; the application is not yet available for use.

Privacy & data use

This informational page has no account registration, analytics scripts, advertising, contact forms or application-level collection of personal information. The hosting provider may process standard request information under its own policies.

The planned application will use authorized access only, with minimum necessary permissions. Provider data will be processed and retained only as permitted by the applicable agreement. Historical storage, data exports and external AI processing will remain disabled unless authorized. Credentials and tokens will not be published or shared.

No sale or redistribution of fantasy league data is planned. This notice will be updated before any live application is released.

# CK Fantasy Manager — public website

Static, informational GitHub Pages landing page for the private CK Fantasy Manager prototype.

## Site
https://dkalade2006.github.io/Ck-fantasy-manager-site/

## Development
- Entry point: `index.html` (HTML and embedded CSS, no build dependencies).
- The public roadmap is maintained manually. Check the [application repository](https://github.com/dkalade2006/Ck-fantasy-manager) before updating sprint statuses.
- Do not equate a merged PR with owner UAT acceptance. Sprint 6 remains in validation until [#32](https://github.com/dkalade2006/Ck-fantasy-manager/issues/32) is corrected and [#30](https://github.com/dkalade2006/Ck-fantasy-manager/issues/30) is accepted.
- Yahoo API integration is an independent authorization-gated track. Do not imply approval, live access or public release without evidence.
- Keep the site informational and static; preserve privacy disclosures and avoid third-party scripts or user data collection.

## Review checklist
1. Verify sprint and feature claims against current project issues.
2. Check desktop and narrow mobile layouts, keyboard navigation, focus visibility and text contrast.
3. Verify links and anchor navigation.
4. Confirm no external scripts, tracking, credentials or personal data.
5. Request owner UAT and approval before merging.
6. After merge, verify the published GitHub Pages site and links.
